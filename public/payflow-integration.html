Payment integration

POST /v1/payments
Authorization: Bearer pk_test_...
Idempotency-Key: order-1001

{
  "amount": 99900,
  "currency": "INR",
  "orderId": "order-1001",
  "simulation": "success"
}

Payout integration

POST /v1/payouts
Authorization: Bearer pk_test_...
Idempotency-Key: payout-1001

{
  "amount": 50000,
  "mode": "IMPS",
  "beneficiary": {
    "name": "Example Beneficiary",
    "accountNumber": "XXXXXXXXXXXX",
    "ifsc": "HDFC0000001"
  }
}

For the hackathon, payments and payouts use internal simulators. A real PSP/bank provider can later be plugged in behind the provider interface without changing merchant APIs.
